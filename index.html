How to read the numbers

  • Hot is the best of the three tries and cold is the first. Totals of the best tries, recomputed from the traces, differ from the table by less than 2 %.
  • Mean is not the total divided by 43. The values match a geometric mean shifted by 10 ms, so long queries affect it less than they affect the total. This formula was derived from the traces and does not appear in the original run summaries.
  • ≈ marks values computed from the report's traces because the run summaries don't include them. Trace times run slightly below what the client measured.
  • Recorded covers everything the probe saw: all tries and housekeeping statements. It is not a benchmark result, so don't compare runs on it.
  • Probe cost. For GPU, each variant was compared over a single pass, with the probe collecting metrics every second (the default is 15 s) and full query text. For CPU, the baseline is VP7's run without the probe, and the difference is too small to measure.
  • Gaps in the data. All four reports lack read timing and checkpoint logs, so rules A18 and A28 are incomplete. The advisor asks for track_io_timing and log_checkpoints to be turned on.
